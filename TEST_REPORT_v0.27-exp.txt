IMPLEMENTED
-----------
GM THEME
- Explicit light foreground colors on dark GM command/combat/threat/check/VTT surfaces.
- Dark GM form controls use light text/placeholders.
- Light paper Ranger dossiers explicitly retain dark ink.

VTT ORGANIZATION
- Tactical Tools split into Navigate + Measure, Markup + Templates, GM Scene Layers, and Layer History groups.
- Token HUD contains token-specific state only.
- Map library + grid calibration moved into independent GM Scene panel.
- Spatial Awareness remains independent.
- Mobile bottom control bar exposes zoom/Fit, Tools, Token, Map, Range, Dice.

ELEVATION
- Persistent quick elevation dock for selected movable token.
- +/- 5 ft controls, direct 5-ft numeric entry, Ground reset.
- Token badge continues to display nonzero elevation.
- Pre-combat elevation staging is free.
- During the active combatant's turn, absolute vertical feet traveled are added to movement spent.
- Multiplayer server owns canonical vertical movement accounting.
- Elevation state snaps to 5-ft increments.

MOBILE
- Horizontal touch-scrolling primary navigation.
- 16px phone form controls.
- dynamic-viewport-bounded rule/confirm dialogs with internal scrolling.
- VTT floating panels become bounded bottom-sheet panels on phones.
- nonessential VTT mobile header branding hidden so Return/End Session remain reachable.
- closed dice dock hidden on mobile VTT; DICE button opens it above the bottom bar.
- one-finger empty-map pan in Select/Pan mode.
- token drag remains one-finger movement.
- two-finger pinch zoom centered on gesture.
- midpoint motion during pinch pans naturally.
- double-tap quick zoom.
- live zoom transform avoids full VTT rebuild during gesture frames.
- VTT render preserves viewport scroll position across ordinary UI rerenders.
